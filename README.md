# 笨猫面试助手（interview-copilot）

一个跑在 Windows 上的面试 / 笔试实时 AI 助手：本地回环录音 → 实时转写 → 只对面试官的提问生成口语化回答；截图识题可以只截当前窗口或手动框选一块区域；还可以扫码把界面投到手机上，电脑端退到后台保活。

> 仅用于个人学习与技术研究。请遵守面试/考试方的规则，不要用它做违规的事。

---

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 实时转写 | 采集系统回环音频（腾讯会议、飞书、Zoom 等），本地 faster-whisper 离线转写，也可切在线 ASR |
| 面试回答 | 只针对“面试官最近提出的问题”作答，先给结论再给要点，默认 30 秒口播长度 |
| 提问筛选 | 本地关键词粗判“像不像提问”，命中才调用大模型，省 token、少误答 |
| 截图识题 | 三种范围：只截当前活动窗口 / 手动框选 / 整个桌面；支持多张截图合并提交 |
| 手机远程 | 同一局域网扫码打开手机页面，可看实时转写、截图、提问，电脑端不再弹答案框 |
| 个人知识库 | 把你真实的简历、项目细节写进 `knowledge/profile.md`，AI 按真实经历回答，不编造 |
| 悬浮窗 | 无边框置顶，可调透明度、字号、位置 |
| 打包分发 | 一键打包成 `笨猫面试助手.exe`，配置、知识库、语音模型一起带走 |

---

## 环境要求

- Windows 10 / 11（截图与回环录音依赖 Windows API）
- Python 3.10+（开发环境为 3.11）
- 一个 OpenAI 兼容的大模型接口（默认按 DeepSeek 配置；视觉识题需要支持图片输入的模型）
- 可选：麦克风/扬声器正常、手机与电脑在同一个 Wi-Fi 下

## 快速开始

### 1. 安装依赖

```powershell
cd "interview-copilot"
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. 配置 API Key

把示例配置复制成真实配置，然后填 Key：

```powershell
Copy-Item config.example.json config.json
```

需要填的两处（其余保持默认即可）：

```json
{
  "text_api": { "api_key": "你的文本模型 Key" },
  "vision_api": { "api_key": "你的视觉模型 Key" }
}
```

也可以先直接启动，在界面「模型与音频」标签页里填写并点「保存设置」。

> `config.json` 已经在 `.gitignore` 里，不要提交到任何仓库。

### 3. 准备个人知识库

打开界面「知识库」标签页，把你的真实经历写进去；或直接编辑：

```text
knowledge/profile.md
```

建议写：教育背景、工作经历、每个项目的「背景 / 我负责的部分 / 技术选型 / 难点 / 结果数据」、掌握的技能与熟练度、不擅长的地方。
资料里没有的内容，模型会保守表述并提示补充，而不是编造。

> `knowledge/profile.md` 同样在 `.gitignore` 里，属于隐私内容。

### 4. 本地语音识别模型（可选）

默认使用本地 faster-whisper（`small` + `int8`），首次转写会自动下载到 `models/whisper`。
国内网络可在配置里保留 `asr_local.hf_endpoint`（默认 `https://hf-mirror.com`）。
如果不想下载模型，把 `asr_local.enabled` 改成 `false`，并在「模型与音频」里配置在线 ASR。

### 5. 启动

```powershell
python main.py
```

启动后主窗口出现，同时在系统托盘常驻。重复双击只会提示“程序已经在运行”，不会开第二个实例。

## 界面说明

- **控制**：开始/停止监听、截图识题、手动回答、悬浮窗、手机远程；下面是自动回答开关、提问筛选开关、截图范围选择。
- **模型与音频**：文本模型、视觉模型、在线 ASR、本地 ASR、回环音频参数。
- **知识库**：编辑并保存 `knowledge/profile.md`。
- **提示词**：面试回答与笔试识题的系统提示词，可自行改写风格。

窗口可以自由缩放，内容放不下时会出现滚动条。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + L` | 开始 / 停止实时转写 |
| `Ctrl + Alt + S` | 截图并识题 |
| `Ctrl + Alt + Enter` | 立即根据当前转写生成回答 |
| `Ctrl + Alt + H` | 显示 / 隐藏悬浮答案窗 |
| `Ctrl + Alt + Shift + Q` | 退出程序 |

快捷键在 `config.json` 的 `hotkeys` 里修改。

## 使用流程

### 面试（实时听 + 自动答）

1. 打开腾讯会议 / 飞书 / Zoom 等，进入面试。
2. 点「开始监听」（或 `Ctrl+Alt+L`），确认「模型与音频」里的音频源是 `loopback`（系统回环）。
3. 勾选「自动回答」和「仅在像“提问”时才自动回答」。
4. 面试官提问后，悬浮窗会直接给出可念的回答；想看全文按 `Ctrl+Alt+H`。

转写里同时会有你和面试官的声音，这没关系：提示词要求模型只回答面试官的问题，其余内容输出“（等待问题）”。开启提问筛选后，闲聊根本不会触发请求。

### 笔试 / 在线测评（截图识题）

1. 「截图范围」选：
   - **只截当前活动窗口**（推荐）：截图前助手会先自动隐藏自己，截完再恢复；
   - **手动框选区域**：拖动框选题目区域，松手截图，`Esc` 或右键取消；
   - **整个桌面**：多显示器时截全部屏幕。
2. 按 `Ctrl+Alt+S` 或点「截图识题」，答案会显示在悬浮窗。
3. 一道题跨屏时：用手机端的「追加截图」多次截取，再点「提交」合并理解；电脑端也可以连续截图，最后一起提交。

### 手机远程（局域网）

1. 点「手机远程」（或托盘菜单「手机远程（扫码）」），弹出二维码。
2. 手机连同一个 Wi-Fi，扫码打开页面。
3. 电脑端自动最小化到托盘，只做后台保活：不再弹答案框，转写/回答/识题结果都显示在手机页面上。
4. 手机页面可以：看实时转写、点截图、追加多张截图并提交、手动提问、开关自动回答、清空内容。
5. 关闭二维码窗口即断开；页面提示「会话已失效，请重新扫码」时，重新生成二维码即可（token 是一次性的）。

## 打包成 exe

```powershell
pip install pyinstaller
python build.py
```

产物：`dist/笨猫面试助手/笨猫面试助手.exe`。

打包脚本会自动把 `config.json`、`knowledge/`、`models/` 复制到 exe 同级目录，整个文件夹拷走即可直接用。
注意：重新打包会重建 `dist/笨猫面试助手`，如果你在 exe 里改过配置，重打包后需要重新填一次。

## 常见问题

**Q：转写一直是空的？**
A：确认「模型与音频」里音频源是 `loopback`，且会议软件正在出声；把 `silence_rms` 调小（例如 `0.001`）可以提高灵敏度。首次使用本地模型需要等它下载完成。

**Q：模型下载很慢或失败？**
A：保留 `asr_local.hf_endpoint` 为 `https://hf-mirror.com`，或手动把模型放到 `models/whisper/faster-whisper-small/`（目录里要有 `model.bin`）。

**Q：截图截到了助手自己？**
A：截图前助手会先隐藏面板和悬浮窗再截，正常不会截到自己。如果仍出现，检查是否把「截图范围」设成了「整个桌面」，并改用「只截当前活动窗口」。

**Q：多显示器截图位置偏移？**
A：多屏且缩放比例不一致时会有少量偏差。把各显示器缩放设为相同比例（如都用 100% 或都用 150%）即可精确。

**Q：手机关掉页面后电脑端没恢复？**
A：电脑端只做后台保活是设计行为。关掉二维码窗口（或托盘里再点一次「手机远程」）就恢复电脑端展示。

**Q：为什么回答里出现“资料里没有”这类话？**
A：知识库没写到相关内容。补充 `knowledge/profile.md` 后重新提问即可。

## 隐私与安全

- `config.json`（含 API Key）和 `knowledge/profile.md`（含个人简历）默认不进入版本库。
- 手机远程用的是局域网 HTTP + 一次性 token，仅在开启期间有效，不要把这个端口暴露到公网。
- 音频、截图只在本机处理；只有需要模型回答时，才会把**转写文本或截图**发送给你配置的模型接口。
